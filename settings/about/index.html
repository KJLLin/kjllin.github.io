KJLLin
版本 1.0 · Build 2026

KJLLin 是一个现代化的个人网站平台，融合了社交互动、云端存储、休闲游戏等功能。本站采用 Apple Design Language 设计语言，致力于提供优雅、流畅的用户体验。

功能模块

首页 — 个人主页，展示动态与问候

站内信 — 实时私信系统，支持对话管理

游戏中心 — 石头剪刀布、恐龙快跑、2048、贪吃蛇、舒尔特方格

资源云盘 — 云端文件存储，支持上传/下载/预览

文章广场 — Markdown 社区文章，基于话题的交流

设置 — 账号安全、个人资料、设备管理、主题外观

安全保障

本站实施了多层级安全防护措施，包括：

• 客户端输入净化与 XSS 防护

• 内容安全策略 (CSP) 头部限制

• 人机验证 (hCaptcha) 防滥用

• 操作频率限制机制

• Supabase RLS 数据库级权限控制

• 安全重定向校验防开放重定向攻击
